# 变更：AT 指令任务池可移植化与扩展

## 为什么
- 已完成原子任务与任务池初版，需要覆盖大部分 AT 指令同步流程
- 目标运行环境包含裸机与 RTOS，需要提高可移植性
- 软件中要求避免动态内存分配
- 命名规则要求禁止驼峰，统一使用下划线

## 变更内容
- 支持多个任务池实例，但同一时刻仅允许一个活跃池执行，切换由上层显式触发
- 增加同步机制抽象接口，兼容裸机与 RTOS
- 约束任务池与任务状态使用静态内存
- 规格中明确同步 AT 指令流程与异常路径
- 新增接口与结构体命名统一为下划线风格
- 允许重划分结构体内容，并保持现有 API 兼容
- 保持现有任务执行的核心逻辑不变
- 划分 Usr 目录结构，分离可移植接口与测试接口
- 提供可调试的测试程序
- 采用严格 TDD 流程推进变更
- 提供最小 TDD 用例骨架

## 影响
- 受影响的规格：at-task-scheduling
- 受影响的代码：任务池与原子任务相关模块
